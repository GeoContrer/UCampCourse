# Proyecto M2: Fundamentos de Python

Este repositorio contiene la solucion a los retos practicos del modulo 2 del bootcamp, el objetivo siendo el entrender el uso de las estructuras o comandos "if, elif, else" y el manejo basico de datos en Python

# Descripcion de los retos
El programa principal Geovanni_Mendez_proyectoM2.py contiene dos funciones:

1. ** Longitud de frase:** Esta evalua si una palabra ingresada por el usuario cumple con la longitud especificada de 4 a 8 caracteres.
2. ** Encuentra el cuadrante:** solicita coordenadas X e Y para determinar en que cuadrante del plano se ubica el punto ingresado por el usuario.

# Como ejecutar?
1. Asegurate de tener instalado Python 3.x.
2. Descarga el archivo Geovanni_Mendez_proyectoM2.py .
3. Abre una terminal en la carpeta del archivo.
4. Ejecuta el comando: Geovanni_Mendez_proyectoM2.py
